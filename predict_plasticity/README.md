# Plasticity Classification for HEA Descriptors

This module applies a trained ONNX classification model to the descriptor
tables generated by `calc_descriptors`, producing plasticity predictions for
six-principal-element high-entropy alloys.

## Model Files

Place the following files under `model_files/` (already included in this
repository):

| File | Description |
|------|-------------|
| `model.onnx` | Trained plasticity classification model in ONNX format |
| `minmax_params.pkl` | Pickle file containing `Min` and `Max` arrays for feature normalization |
| `feature_names.json` | JSON file listing the descriptor columns required by the model |

The current model expects five descriptors:

```json
["ave_fe3", "rmse_fe3", "pair_fs2", "ave_fs3", "lambda_data"]
```

## Requirements

Install dependencies with `pip`:

```bash
pip install -r requirements.txt
```

Or use `uv` to sync with the rest of the repository:

```bash
uv pip install -r requirements.txt
```

## Usage

### Default paths

By default the tool reads descriptors from `/data/descriptors/hea_6_c_{system_id}.parquet`
and writes predictions to `/data/predictions/pred_{system_id}.parquet`.

Run predictions for systems 1 through 10:

```bash
cd predict_plasticity
export PLASTICITY_START=1
export PLASTICITY_END=10
export PLASTICITY_INPUT_DIR=/path/to/descriptors
export PLASTICITY_OUTPUT_DIR=/path/to/predictions
python main.py
```

### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `PLASTICITY_START` | `1` | First system index to predict |
| `PLASTICITY_END` | `5005` | Last system index to predict |
| `PLASTICITY_INPUT_DIR` | `/data/descriptors` | Directory containing `hea_6_c_*.parquet` |
| `PLASTICITY_OUTPUT_DIR` | `/data/predictions` | Directory for output `pred_*.parquet` |
| `PLASTICITY_INPUT_PATTERN` | `hea_6_c_{system_id}.parquet` | Input filename pattern |
| `PLASTICITY_OUTPUT_PATTERN` | `pred_{system_id}.parquet` | Output filename pattern |
| `PLASTICITY_BATCH_SIZE` | `100000` | Inference batch size |
| `PLASTICITY_MODEL_PATH` | `model_files/model.onnx` | ONNX model path |
| `PLASTICITY_MINMAX_PATH` | `model_files/minmax_params.pkl` | Min-Max params path |
| `PLASTICITY_FEATURE_NAMES_PATH` | `model_files/feature_names.json` | Feature names path |

### As a library

```python
from predict_plasticity.predictor import PlasticityPredictor, predict_one_system

predictor = PlasticityPredictor()
output_path = predict_one_system(1, predictor=predictor)
print(output_path)
```

## Prediction Pipeline

For each element system:

1. Read the required descriptor columns from the input parquet file.
2. Apply Min-Max normalization using the pre-computed training parameters:
   `normalized = (descriptors - Min) / (Max - Min)`.
3. Run ONNX inference in batches to keep memory usage low.
4. Write the `con_index` and prediction results to an output parquet file.

The default ONNX model returns a probability matrix of shape `(N, 3)`, where
`N` is the number of composition rows (over 10 million per system).

## Notes

- The model and normalization parameters must come from the same training run;
  mixing models and scalers from different trainings will produce invalid
  results.
- Predictions are written preserving the original `con_index` order, so they
  can be joined back to the descriptor tables or the `hea_con_6` table.
